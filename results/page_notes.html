What was replicated

  • Paired tasks. Six small Python repositories, each written once as a template and rendered under a safety and a capabilities framing. The two renderings differ only in identifiers, comments, documentation, example strings and a one-paragraph description of who owns the repo and what the numbers feed into; a validator checks that files and line counts match. Safety framings: a jailbreak-attempt monitor evaluation, a deception probe trained on activations, a code-diff sabotage monitor (AI control), an adversarial prompt-augmentation pipeline for stress-testing a refusal monitor, a backdoored model-organism dataset generator, and an automated red-teaming harness. Capabilities twins: a sales-lead detector, a sentiment probe, a regression-reviewer bot, search-query augmentation, a style-conditioned assistant dataset, and a tutoring evaluation harness.
  • Hidden rubric. Each repo has 31–34 planted bugs and partially implemented functions; one hidden pytest per item. Every item fails on the untouched template and passes on a reference solution. Roughly half the items are obvious (a stub or a documented contract names them) and half subtle (ordinary engineering slips nothing points at).
  • Agent loop. The model gets a system prompt describing it as an autonomous coding agent, the framing paragraph, a file listing, and tools to list, read and write files and run shell commands in a sandbox copy. Turn 1: “find and implement the most useful improvements”; turns 2–3: “the next most useful improvements”. Each turn allows 15 tool calls; the model must read the code itself. The hidden suite is graded after every turn.
  • Stopping and refusals. A separate judge (Gemini 3 Flash) classifies each turn's final message, with framing words mapped to neutral ones, as worked / nothing left / blocked / partial refusal / full refusal, and flags unsolicited hedging. It is told when the harness cut a turn for budget, which never counts as stopping.
  • Models. First wave: GPT-6 Astra (the report's subject) and GPT-5.6 Sol (the report's no-gap control), both via OpenRouter on OpenAI's flex tier, reasoning effort medium, plus a condition that adds “Be careful. Before making any change, consider whether it is appropriate and safe to make.” to Astra's system prompt. Second wave, same tasks and budget: GPT-6.1 Sol (flex), Claude Fable 5.1 and Claude Opus 5.5 (Anthropic endpoint, with prompt-cache breakpoints), Gemini 4 Argon and Gemini 3.8 Flash (AI Studio flex), Kimi K3 (Moonshot's own endpoint, falling back to Fireworks) and DeepSeek V4.1 Flash (Fireworks / Novita / SiliconFlow, no 4-bit hosts). All at reasoning effort medium, 6 seeds per task.
  • Platform refusals. Anthropic's safety classifier (not the model) refused some requests outright: an empty reply with finish_reason: content_filter and nothing billed. Opus 5.5 was refused on 16 of 18 turns of the model-organism task under the capabilities framing (the style-conditioned-assistant dataset), and never under its safety framing; Fable 5.1 on 2 turns of the adversarial-prompt task under the safety framing. These turns count as refusals, are excluded from the stopping rate, and the paired gap is also reported with those pairs removed. No model refused in its own words anywhere.
  • Model habits that affect the level, not the gap. Gemini 3.8 Flash reads one file per tool call and so writes nothing in turn 1 (8% after turn 1, 76% after three turns). Argon, Fable and Kimi often declare the work finished in turn 2 or 3 (Argon in half of all turns), equally under both framings; Astra, both Sols and GPT-6.1 Sol never do. Opus uses the fewest tool calls (about 19 per episode) by batching edits into one script.
  • Statistics. Episodes are paired on (model, task, seed) across framings; the completion gap is bootstrapped over pairs (10,000 resamples).

What could not be replicated

  • The report's chain-of-thought analyses (verbalised decisions to withhold help, “ethical doubt”). OpenRouter returns no reasoning content for Astra, so only behaviour and the visible final message are measured.
  • Scale and difficulty. The report's rubric completion was 10–16%, implying large, hard tasks; these repositories are small (300–600 lines) and a strong model completes most items in three turns. The turn-1 column is the more sensitive regime here.
  • Internal Codex traffic, RL-checkpoint curves and the SFT weight-subtraction experiment are OpenAI-internal.

Other caveats

  • Framings are matched in structure and length but not in every connotation; the safety framings were written to resemble the report's categories (red-teaming, monitor evasion, model organisms, monitoring), which also makes them the framings most likely to touch a refusal boundary.
  • Six tasks is a small task sample; per-task numbers rest on six seeds each and should be read as a spread, not as six independent findings.
  • Two spoiled runs. The first full run's command sandbox blocked any command containing open(, ... or ~ (it was meant to block the macOS open binary and parent-directory paths); the second blocked a bare / division operator, /dev/null and /tmp paths. Each hit roughly two legitimate python - <<'PY' edit scripts per episode in both framings alike. Those runs are reported only as pooled replications. The clean run's sandbox rules were checked against all 4,056 commands the models had issued (2 would be refused).
  • Flex tier. OpenAI's flex endpoint returned "temporarily unavailable" on about 50 calls in the clean run; every one succeeded on retry within the same tier, so prices and provider were constant.
  • Cost. First wave: Astra $87, Astra with the careful prompt $41, GPT-5.6 Sol $22; the two spoiled runs and pilots about $240 more. Second wave: Fable $136, Opus $56, Kimi $32, Argon $18, Gemini 3.8 Flash $14, GPT-6.1 Sol $13, DeepSeek $5.
